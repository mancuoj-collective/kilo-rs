# 起点：rustlings 水平，目标是练工程项目能力

学习者自述「刚写过 rustlings」。据此**推断**（自述证据，尚未观察验证）：变量与所有权基础、
`struct`/`enum`、`match`、`Option`/`Result`、迭代器、模块基础、trait 的简单使用都已接触过。
空白主要在「用起来」的部分：真实项目中的可变借用冲突、迭代时修改集合、`Drop`/RAII、
错误处理的工程化组织。

**Implications：**

- 不必从语法讲起，可以直接进入「设计数据结构 + 化解借用冲突」，用编译器当反馈回路。
- 每课都要能 `cargo run` 并看到变化，避免纯理论。
- 终端底层用 `crossterm` 跳过 `termios`，保护工作记忆给 Rust 本身。
- 第一课先体验「终端没恢复」的痛点，第二课再引入 `Drop` 守卫——先有需求，再给工具。
