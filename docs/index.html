用 Rust 重写 kilo

一门项目驱动的 Rust 课程 · 现代写法 · 边写边学

从零开始，把 kilo——一个一千行出头的文本编辑器—— 用现代 Rust 一步步重写出来。每一课都是一个小胜利：能编译、能运行、能亲眼看到变化。

这门课的目标

  • 把 rustlings 学到的语法，真正用在有状态、有交互、会长期演进的项目上；
  • 练出「设计数据结构 → 处理所有权与借用 → 拆模块」的真实工程能力；
  • 最终真正拥有一个能运行的、由自己一行行写出来的编辑器。

课程目录

  1. 第 1 课 · 接管终端 —— raw mode、事件循环，用 Drop 守卫保证终端一定被恢复。
  2. 第 2 课 · 干净的画布 —— 备用屏幕、panic hook，开始一帧一帧地画屏幕。
  3. 第 3 课 · 打开一个文件 —— 命令行参数、把文件读进 Vec<String>、渲染到画布。
  4. 第 4 课 · 第一次重构 —— 拆出 tui.rs 与 lib.rs，第一次做「行为不变的搬家」。
  5. 第 5 课 · 光标与滚动 —— 光标移动、视口滚动，写出第一批不依赖终端的单元测试。
  6. 第 6 课 · 字符 ≠ 列 —— tab 与宽字符、cx/rx 换算，引入 Row。

进行中 第 7 课（编辑与保存：插入、换行、退格、写回磁盘）正在路上。

参考文档

  • 现代 Rust 惯用法 —— 本课程的风格约定：import 顺序、let-else、RAII、错误处理、字符串转换……
  • 架构与文件结构 —— 什么时候该分文件、什么是深模块、kilo-rs 的目标结构。
  • 终端基础与 crossterm API —— raw mode、事件循环骨架、按键模型、常见坑。

课程的约定

  • 代码用英文，讲解用中文：注释（//、///、//!）和运行时字符串 （expect、panic 信息）一律英文；课程正文保持中文。理由：中文里「字符」等词有歧义， 而英文术语精确（code point / column / byte），也与 Rust 生态一致。
  • 每课都能跑：任何一步都应能 cargo run 并观察到变化。
  • 质量门：以 cargo clippy --all-targets -- -D warnings 零告警为底线， unsafe 一律禁止。
  • 先体验问题，再引入解法；重构只做「行为不变的搬家」，绝不一边重构一边加功能。
