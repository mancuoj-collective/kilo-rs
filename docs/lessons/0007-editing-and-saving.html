第 7 课 · 编辑与保存

kilo-rs 课程 · Lesson 0007 · 预计 45–60 分钟 · 加功能，也是借用检查器的主战场

文件能看了、光标能动了，但它还是只读的。这一课让它真正可写： 插入字符、回车换行、退格删除，再按 Ctrl+S 写回磁盘。 Row / Editor 会长出修改方法——也是借用检查器正式上强度的地方。

本课成果

  • 能敲字、回车、退格；中文与 tab 位置依然正确；
  • 底部出现状态栏，显示文件名，改动后带 [modified]；
  • Ctrl+S 保存到磁盘，[modified] 随之消失；
  • 单元测试增加到 12 个（新增拆分/连接/插入/回车/退格）。

编辑的本质：改「行」

光标告诉我们「改哪一行的第几个字符」，真正的修改发生在 Row 上。 三件事支撑起全部编辑：

操作做法
插入一个字符chars.insert(cx, ch)
删除一个字符chars.remove(cx)
回车 / 退格跨行把行拆开（split_off）或接起来（append）

回车：在光标处把当前行切成上下两行。退格在行首：把当前行接到上一行末尾。两者都只是在 Vec<Row> 上增删元素。

借用检查器的正面战场

写「把当前行接到上一行」时，你会撞上本课最典型的冲突：

// bad: two mutable borrows of self.rows at once
let prev = &mut self.rows[self.cy - 1];
let cur = &mut self.rows[self.cy];
prev.append(cur);

编译器会说「cannot borrow self.rows as mutable more than once」。规则是 同一时刻只能有一个可变借用——而这里你有两个。

解法 不要让两行同时被借用。先把当前行从 Vec 里 remove 出来，让它归你所有，再把它的字符 append 到上一行。 冲突消失，语义也更清楚：这一行本来就要没了。

这是 m03-mutability 的核心提问：「冲突说明数据结构用错了吗？」 ——多数时候不是结构错，而是借用的作用域没设计好。先缩小作用域、或先取出来拥有它， 而不是急着 clone() 绕过（那是 m15-anti-pattern 里的头号反模式）。

动手

任务 1 给 src/row.rs 加上编辑方法

在 impl Row 里加入这些方法（其余不变）：

    /// The row's characters as a string (used when saving).
    #[must_use]
    pub fn text(&self) -> String {
        self.chars.iter().collect()
    }

    /// Inserts `ch` at char index `cx` (clamped to the row length).
    pub fn insert_char(&mut self, cx: usize, ch: char) {
        let at = cx.min(self.len());
        self.chars.insert(at, ch);
    }

    /// Removes the char at `cx`, if it exists.
    pub fn delete_char(&mut self, cx: usize) {
        if cx < self.len() {
            self.chars.remove(cx);
        }
    }

    /// Splits the row at `cx`, returning the tail as a new row.
    #[must_use]
    pub fn split_off(&mut self, cx: usize) -> Self {
        let at = cx.min(self.len());
        Self {
            chars: self.chars.split_off(at),
        }
    }

    /// Appends another row's characters to the end of this one.
    pub fn append(&mut self, other: &mut Row) {
        self.chars.append(&mut other.chars);
    }

再加一个测试：

    #[test]
    fn split_and_append_round_trip() {
        let mut row = Row::new("abcd");
        let mut tail = row.split_off(2);
        assert_eq!(row.text(), "ab");
        assert_eq!(tail.text(), "cd");
        row.append(&mut tail);
        assert_eq!(row.text(), "abcd");
    }

任务 2 改 src/editor.rs

新增两个字段（文件名、脏标记）、改 new 的签名，加入编辑与保存方法：

pub struct Editor {
    rows: Vec<Row>,
    /// File name, when the buffer came from (or is saved to) a file.
    filename: Option<String>,
    /// Whether the buffer has unsaved changes.
    dirty: bool,
    cx: usize,
    cy: usize,
    coloff: usize,
    rowoff: usize,
}

impl Editor {
    /// Creates a new editor from the given lines and optional file name.
    #[must_use]
    pub fn new(lines: &[String], filename: Option<String>) -> Self {
        Self {
            rows: lines.iter().map(|line| Row::new(line)).collect(),
            filename,
            dirty: false,
            cx: 0,
            cy: 0,
            coloff: 0,
            rowoff: 0,
        }
    }

    /// Whether the buffer has unsaved changes.
    #[must_use]
    pub fn is_dirty(&self) -> bool {
        self.dirty
    }

    /// File name shown in the status line.
    #[must_use]
    pub fn filename(&self) -> Option<&str> {
        self.filename.as_deref()
    }

    /// The whole buffer as text, rows joined by `\n`.
    #[must_use]
    pub fn serialize(&self) -> String {
        let mut out = String::new();
        for row in &self.rows {
            out.push_str(&row.text());
            out.push('\n');
        }
        out
    }

    /// Writes the buffer to its file. Does nothing when there is no file name.
    ///
    /// # Errors
    ///
    /// Returns the underlying I/O error if the file cannot be written.
    pub fn save(&mut self) -> io::Result<()> {
        let Some(path) = &self.filename else {
            return Ok(());
        };
        std::fs::write(path, self.serialize())?;
        self.dirty = false;
        Ok(())
    }

    /// Inserts `ch` at the cursor.
    pub fn insert_char(&mut self, ch: char) {
        if self.cy == self.rows.len() {
            self.rows.push(Row::new(""));
        }
        if let Some(row) = self.rows.get_mut(self.cy) {
            row.insert_char(self.cx, ch);
        }
        self.cx += 1;
        self.dirty = true;
    }

    /// Splits the current row at the cursor (Enter / Return).
    pub fn insert_newline(&mut self) {
        if self.cx == 0 || self.cy >= self.rows.len() {
            self.rows.insert(self.cy, Row::new(""));
        } else {
            let tail = self.rows[self.cy].split_off(self.cx);
            self.rows.insert(self.cy + 1, tail);
        }
        self.cy += 1;
        self.cx = 0;
        self.dirty = true;
    }

    /// Deletes the char before the cursor; at column 0 it joins with the previous row.
    pub fn delete_char(&mut self) {
        if self.cy >= self.rows.len() {
            return;
        }
        if self.cx == 0 {
            if self.cy == 0 {
                return;
            }
            // Take the current row out so we own it, then append it to the previous one.
            let mut row = self.rows.remove(self.cy);
            let prev = &mut self.rows[self.cy - 1];
            self.cx = prev.len();
            prev.append(&mut row);
            self.cy -= 1;
        } else {
            self.rows[self.cy].delete_char(self.cx - 1);
            self.cx -= 1;
        }
        self.dirty = true;
    }

    // … move_cursor / scroll / current_line_len / current_rx are as in lesson 6

    fn insert_char_updates_row_and_cursor() {

        e.insert_char('c');

    #[test]
    fn enter_splits_the_line() {
        let mut e = Editor::new(&[String::from("abcd")], None);

任务 3 改 src/lib.rs：接按键 + 画状态栏

run 里把文件名交给编辑器，并处理编辑按键：

    // Read the file name from argv; with no argument, start with an empty buffer.
    let path = env::args().nth(1);
    let lines = match &path {
        Some(path) => fs::read_to_string(path)?
            .lines()
            .map(str::to_owned)
            .collect(),
        None => Vec::new(),
    };

    let mut editor = Editor::new(&lines, path);
    // … after Terminal::enter():
    loop {
        match event::read()? {
            Event::Key(key) if key.is_press() => {
                let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
                match key.code {
                    KeyCode::Char('q') if ctrl => break,
                    KeyCode::Char('s') if ctrl => editor.save()?,
                    KeyCode::Char(ch) if !ctrl => editor.insert_char(ch),
                    KeyCode::Enter => editor.insert_newline(),
                    KeyCode::Backspace => editor.delete_char(),
                    // Forward delete: step right, then delete what is now behind the cursor.
                    KeyCode::Delete => {
                        editor.move_cursor(Move::Right);
                        editor.delete_char();
                    }
                    KeyCode::Up => editor.move_cursor(Move::Up),
                    KeyCode::Down => editor.move_cursor(Move::Down),
                    KeyCode::Left => editor.move_cursor(Move::Left),
                    KeyCode::Right => editor.move_cursor(Move::Right),
                    KeyCode::Home => editor.move_cursor(Move::Home),
                    KeyCode::End => editor.move_cursor(Move::End),
                    _ => {}
                }
            }
            _ => {}
        }
        draw(&mut editor)?;
    }

Delete 是前向删除（删光标处的字符），与退格相反。原版 kilo 的写法是 「先右移、再退格」——复用已有动作拼出前向删除，我们照抄。 一个原版同样存在的边角：在最后一行行尾按 Delete，光标会先落到「不存在的下一行」。

draw 里留出最后一行做状态栏：

    let text_height = height.saturating_sub(1); // keep the bottom row for the status line

    editor.scroll(text_height, width);

逐段拆解

  • split_off / append 为什么是方法而不是就地拼：它们表达的是「行的拆分与连接」这一个概念， 放在 Row 上，编辑逻辑就都能用「取出一行、处理、放回」这套动作写，不必在 Editor 里摆弄字符数组。
  • let tail = self.rows[self.cy].split_off(self.cx);：这一句的借用只持续到分号。 先把尾段「切出来成为新行」（拥有它），再 rows.insert——两件事不在同一时刻借用 self.rows。
  • let mut row = self.rows.remove(self.cy);：连接行的关键。先把当前行从 Vec 里拿掉 （remove 返回拥有的 Row），它就不再是 self.rows 的一部分， 于是可以放心地同时持有「上一行的可变借用」和「这一行」。
  • 按键 match 的顺序：带 guard 的 Char('q') / Char('s') 必须排在通用 Char(ch) 之前， 否则 Ctrl+S 会先被当成「插入字符 s」；通用 Char(ch) 再加 !ctrl 守卫， 让其它 Ctrl 组合键被忽略而不是插入字母。
  • 把 ctrl 绑一次：key.modifiers.contains(KeyModifiers::CONTROL) 在三个 guard 里都要用。 同一个决策出现三处，就按 Rule of Three 先 let ctrl = …; 绑一次再 match—— 只算一次，意图也更清楚。（抽成函数也可以，但这里直接绑更省一层间接。）
  • 状态栏用掉最后一行：text_height = height - 1，并且 scroll 也用它—— 正文区域和滚动必须一致，否则光标会跑到状态栏上。
  • dirty 的读写闭环：编辑方法置 true，save 置 false， 状态栏读它。一个字段「只写不读」在严格 lint 下会报 dead_code——状态栏让这个字段有意义。
  • 保存的错误用 ?：fs::write 可能失败（磁盘满、无权限）， save() 返回 io::Result，run 里 editor.save()? 交给 color-eyre 打印。 这是 m06 的「可预期的失败 → Result + ?」。

反模式提醒 如果你下意识想「那我 clone() 一份不就行了」——先停一下。 m15-anti-pattern 把「用 clone 绕过借用检查」列为头号反模式：它掩盖了真正的所有权问题， 还白白复制数据。本课两次冲突的解法都是重新安排所有权（切出去、取出来），而不是复制。

小测

1. 连接两行时，为什么先把当前行 remove 出来？

  • 避免同时可变借用 self.rows 两次
  • 因为 Vec 不允许按下标读取元素
  • 因为 append 只能作用于拥有所有权的行
  • 为了顺带清空当前行的字符数组
看答案

第一个。remove 返回一个拥有的 Row，它脱离了 self.rows， 所以「上一行的可变借用」和「这一行」可以同时存在。第二条与第四条都是错的，第三条也不是原因—— append 收 &mut Row，用 &mut 就行。

2. Ctrl+S 的 match 臂为什么必须排在 Char(ch) 之前？

  • 否则 Ctrl-S 会先被当成「插入字符 s」
  • 否则编辑器会在保存前多插入一个换行
  • 否则 save 会拿到错误的文件路径
  • 否则两个分支都会被执行两次
看答案

第一个。match 从上往下匹配，第一条命中的臂胜出。Char('s') 带 CONTROL guard 更具体， 必须在前；否则会把 Ctrl+S 理解成普通字符并插入 s。

3. 按 Ctrl+S 之后，状态栏的 [modified] 为什么消失？

  • 保存成功把 dirty 置回了 false
  • 状态栏每帧重新渲染时会自动清空文字
  • 退出编辑器后状态栏才会刷新标记
  • 文件名变化导致标记被隐藏
看答案

第一个。save() 在写完文件后执行 self.dirty = false；下一帧状态栏据此不再显示 [modified]。标记反映的是「缓冲区与磁盘是否一致」。
