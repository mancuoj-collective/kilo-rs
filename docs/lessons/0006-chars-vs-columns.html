你在第 5 课末尾发现：光标经过中文时「要按两下才走一个字」。这是个真 bug，根因是 「1 个字符」不等于「1 列」。这一课引入 Row，把 逻辑字符位置 cx 和 显示列 rx 彻底分开， 一次性修好光标、截断、横向滚动三处。

本课成果

  • 光标经过中文 / 全角字符时，一次跨越 2 列，位置正确；
  • tab 展开为制表位（不再交给终端自行展开）；
  • 超宽行按列截断，不再触发终端自动换行、错位；
  • 新增 src/row.rs 和一批单元测试（共 8 个），全部不依赖终端。

为什么 char ≠ column

用「第几个字符」来标记光标很自然，但屏幕是按「第几列」来画的。这两者只在「所有字符都占 1 列」时才相等。 真实情况里有三种反例：

字符占几列例子
制表符 \t1 到 8 列（对齐到下一个制表位）取决于它当前所在的列
CJK / 全角字符2 列中文、日文、……
组合字符0 列附加在前一个字符上的声调符号等

关键 tab 和宽字符是同一个问题：一个逻辑单位映射到 N 个显示列。 原版 C kilo 的 editorRowCxToRx 本来就是为 tab 写的——我们只是把 「宽字符也占 N 列」一并交给同一套机制。

cx 与 rx：两套坐标

记号含义用途
cx第几个字符光标移动、插入 / 删除
rx第几显示列画光标、横向滚动、截断

换算由 Row 负责：cx_to_rx(cx) 把字符下标转成起始列， rx_to_cx(rx) 反过来。光标位置、横向滚动都改用 rx；移动和编辑仍用 cx。

「字符」有四种含义 这是混淆的根源，分开看：

概念术语中 是多少Rust 里怎么看
字节byte3s.len()
Unicode 标量值Rust 的 char / 码点1s.chars().count()
字素簇grapheme cluster1需 unicode-segmentation
显示列display column2unicode-width

本课程里 cx 数的是第二种（Rust 的 char，一个汉字 = 1）， rx 数的是第四种（显示列，一个汉字 = 2）。所以「两下才走一个中文」 并不是说一个中文由两个字符组成，而是「按键次数」（按码点算）和「显示列」对不上。

已知局限：按码点计数，e + 组合字符会被当成 2 个字符，需要按两次退格才能删掉视觉上的一个 é；emoji 家族同理。「按字素簇编辑」留到以后的一课。

动手

任务 1 加依赖

在 Cargo.toml 的 [dependencies] 里加一行（本地缓存里已有，可离线构建）：

unicode-width = "0.2"

它提供 UnicodeWidthChar::width(ch) -> Option<usize>：宽字符返回 2，普通字符 1，控制 / 组合字符返回 0 或 None。

任务 2 新建 src/row.rs

//! One line of text, and the conversion between char position and display column.
//!
//! The key fact: **a char does not always occupy one column**.
//! - a tab `\t` occupies 1 to 8 columns (up to the next tab stop);
//! - CJK / fullwidth chars occupy 2 columns;
//! - combining marks occupy 0 columns.
//!
//! The cursor is described by char index (cx) but the screen is drawn by column (rx).
//! This module converts between the two, and slices text by display column.

use unicode_width::UnicodeWidthChar;

/// Tab stop width.
const TAB_STOP: usize = 8;

/// A single line of text.
pub struct Row {
    chars: Vec<char>,
}

impl Row {
    /// Builds a row from a string.
    #[must_use]
    pub fn new(text: &str) -> Self {
        Self {
            chars: text.chars().collect(),
        }
    }

    /// Number of chars in this row (not columns).
    #[must_use]
    pub fn len(&self) -> usize {
        self.chars.len()
    }

    /// Whether this row is empty.
    #[must_use]
    pub fn is_empty(&self) -> bool {
        self.chars.is_empty()
    }

    /// Total display width of this row, in columns.
    #[must_use]
    pub fn width(&self) -> usize {
        self.chars.iter().fold(0, |col, &ch| advance(col, ch))
    }

    /// Display column of the `cx`-th char.
    #[must_use]
    pub fn cx_to_rx(&self, cx: usize) -> usize {
        self.chars
            .iter()
            .take(cx)
            .fold(0, |col, &ch| advance(col, ch))
    }

    /// Index of the char at display column `rx`.
    #[must_use]
    pub fn rx_to_cx(&self, rx: usize) -> usize {
        let mut col = 0;
        for (index, &ch) in self.chars.iter().enumerate() {
            let next = advance(col, ch);
            if next > rx {
                return index;
            }
            col = next;
        }
        self.len()
    }

    /// Returns the text in display columns `[coloff, coloff + width)`.
    #[must_use]
    pub fn render_window(&self, coloff: usize, width: usize) -> String {
        let mut out = String::new();
        let end = coloff + width;
        let mut col = 0;

        for &ch in &self.chars {
            let start = col;
            col = advance(col, ch);

            if col <= coloff {
                continue; // entirely left of the window
            }
            if start >= end {
                break; // window is full
            }

            if ch == '\t' || start < coloff || col > end {
                // Expand tabs to spaces; pad a wide char straddling the edge with spaces.
                let from = start.max(coloff);
                let to = col.min(end);
                out.push_str(&" ".repeat(to - from));
            } else {
                out.push(ch);
            }
        }

        out
    }
}

/// Display width of `ch` starting at column `col` (tabs depend on `col`).
fn advance(col: usize, ch: char) -> usize {
    if ch == '\t' {
        col + (TAB_STOP - col % TAB_STOP)
    } else {
        col + ch.width().unwrap_or(0)
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn wide_chars_take_two_columns() {
        let row = Row::new("中a");
        assert_eq!(row.cx_to_rx(0), 0);
        assert_eq!(row.cx_to_rx(1), 2); // '中' is 2 columns wide
        assert_eq!(row.cx_to_rx(2), 3);
        assert_eq!(row.width(), 3);
    }

    #[test]
    fn tab_aligns_to_next_stop() {
        let row = Row::new("\tx");
        assert_eq!(row.cx_to_rx(1), 8); // a leading tab aligns to column 8
        assert_eq!(row.cx_to_rx(2), 9);
    }

    #[test]
    fn rx_to_cx_is_the_inverse() {
        let row = Row::new("中a");
        assert_eq!(row.rx_to_cx(1), 0); // column 1 is inside '中', still char 0
        assert_eq!(row.rx_to_cx(2), 1);
    }

    #[test]
    fn render_window_clips_by_columns() {
        let row = Row::new("中文");
        assert_eq!(row.render_window(0, 4), "中文");
        assert_eq!(row.render_window(0, 3), "中 "); // a wide char that doesn't fit is padded
    }
}

任务 3 改写 src/editor.rs

把 Vec<String> 换成 Vec<Row>；cursor() 现在返回显示列； scroll 的横向也用 rx：

//! Editable editor state: cursor, viewport, and rendering by display column.

use crate::row::Row;

/// A cursor movement direction.
#[derive(Clone, Copy)]
pub enum Move {
    Left,
    Right,
    Up,
    Down,
    Home,
    End,
}

/// Editor state: buffer, cursor, and viewport.
pub struct Editor {
    rows: Vec<Row>,
    /// Cursor position in **chars**: `cx` is the char index, `cy` the row.
    cx: usize,
    cy: usize,
    /// Top-left of the viewport, in **display columns / rows**.
    coloff: usize,
    rowoff: usize,
}

impl Editor {
    /// Creates a new editor from the given lines.
    #[must_use]
    pub fn new(lines: &[String]) -> Self {
        Self {
            rows: lines.iter().map(|line| Row::new(line)).collect(),
            cx: 0,
            cy: 0,
            coloff: 0,
            rowoff: 0,
        }
    }

    /// Number of rows.
    #[must_use]
    pub fn len(&self) -> usize {
        self.rows.len()
    }

    /// Whether there are no rows.
    #[must_use]
    pub fn is_empty(&self) -> bool {
        self.rows.is_empty()
    }

    /// Cursor position `(display column, row)`; the column is a display column, not a char index.
    #[must_use]
    pub fn cursor(&self) -> (usize, usize) {
        (self.current_rx(), self.cy)
    }

    /// Top-left of the viewport, as `(display column, row)`.
    #[must_use]
    pub fn viewport(&self) -> (usize, usize) {
        (self.coloff, self.rowoff)
    }

    /// Renders row `index` at display columns `[coloff, coloff + width)`.
    #[must_use]
    pub fn render_line(&self, index: usize, coloff: usize, width: usize) -> Option<String> {
        self.rows
            .get(index)
            .map(|row| row.render_window(coloff, width))
    }

    /// Moves the cursor in the given direction (in chars).
    pub fn move_cursor(&mut self, direction: Move) {
        let numrows = self.rows.len();
        match direction {
            Move::Left => {
                if self.cx > 0 {
                    self.cx -= 1;
                } else if self.cy > 0 {
                    self.cy -= 1;
                    self.cx = self.current_line_len();
                }
            }
            Move::Right => {
                if self.cy < numrows {
                    if self.cx < self.current_line_len() {
                        self.cx += 1;
                    } else {
                        self.cy += 1;
                        self.cx = 0;
                    }
                }
            }
            Move::Up => {
                if self.cy > 0 {
                    self.cy -= 1;
                }
            }
            Move::Down => {
                if self.cy < numrows {
                    self.cy += 1;
                }
            }
            Move::Home => self.cx = 0,
            Move::End => self.cx = self.current_line_len(),
        }

        // Moving to a shorter line: clamp the column to the line end.
        self.cx = self.cx.min(self.current_line_len());
    }

    /// Adjusts the viewport so the cursor stays visible; horizontally by **display column** `rx`.
    pub fn scroll(&mut self, rows: usize, cols: usize) {
        let rx = self.current_rx();

        if self.cy < self.rowoff {
            self.rowoff = self.cy;
        }
        if self.cy >= self.rowoff + rows {
            self.rowoff = self.cy - rows + 1;
        }
        if rx < self.coloff {
            self.coloff = rx;
        }
        if rx >= self.coloff + cols {
            self.coloff = rx - cols + 1;
        }
    }

    /// Number of chars in the cursor's row.
    fn current_line_len(&self) -> usize {
        self.rows.get(self.cy).map_or(0, Row::len)
    }

    /// Display column of the cursor.
    fn current_rx(&self) -> usize {
        self.rows
            .get(self.cy)
            .map_or(0, |row| row.cx_to_rx(self.cx))
    }
}

任务 4 更新 src/lib.rs 的 draw

声明 pub mod row;，然后渲染改成「问 Editor 要一行按列取好的文本」：

pub mod editor;
pub mod row;
pub mod tui;

// ... `use` and `run` are unchanged; only:
// let mut editor = Editor::new(&lines);

/// Draws one frame: render the file at the viewport offset and place the terminal cursor.
fn draw(editor: &mut Editor) -> io::Result<()> {
    let (cols, rows) = terminal::size()?;
    let width = cols as usize;
    let height = rows as usize;

    editor.scroll(height, width);

    let (coloff, rowoff) = editor.viewport();
    let (rx, cy) = editor.cursor();

    let mut stdout = io::stdout();
    queue!(stdout, cursor::Hide, Clear(ClearType::All), MoveTo(0, 0))?;

    for y in 0..height {
        let filerow = rowoff + y;
        if let Some(text) = editor.render_line(filerow, coloff, width) {
            queue!(stdout, Print(text))?;
        } else if editor.is_empty() && y == height / 3 {
            queue!(stdout, Print(welcome_line(cols)))?;
        } else {
            queue!(stdout, Print('~'))?;
        }

        if y + 1 < height {
            queue!(stdout, Print("\r\n"))?;
        }
    }

    // The viewport guarantees the cursor is on screen, so these conversions can't fail.
    let cursor_col = u16::try_from(rx - coloff).expect("cursor column should be inside the viewport");
    let cursor_row = u16::try_from(cy - rowoff).expect("cursor row should be inside the viewport");
    queue!(stdout, MoveTo(cursor_col, cursor_row), cursor::Show)?;
    stdout.flush()
}

（truncate / welcome_line 保持不动；它们只服务 ASCII 欢迎语。）

逐段拆解

  • advance(col, ch) 是自由函数而不是方法：它不需要 self。 写成方法的话 clippy::unused_self（pedantic）会提示你——这是它在提醒「这不该是方法」。
  • advance 的参数是 (列, 字符)，不是「字符的固定宽度」——因为 tab 的宽度取决于当前列： col + (TAB_STOP - col % TAB_STOP) 把它对齐到下一个 8 的倍数。所以它算的是「列 → 列」。 width() 与 cx_to_rx() 都是拿它做 fold 的步进函数。
  • ch.width().unwrap_or(0)：unicode-width 对控制字符返回 None，这里当 0 列。 这是简化（原版 kilo 会把控制字符显示成 ^@ 之类的 1 列符号），以后再补。
  • cx_to_rx 用 .take(cx).fold(0, …)：累加前 cx 个字符的宽度。 制表符的宽度依赖当前列（对齐到下一个 8 的倍数），所以必须边累加边算，不能预先算死。
  • fold 就是带累加器的 for：iter.fold(初始值, |累加器, 元素| 新累加器)。 self.chars.iter().fold(0, |col, &ch| advance(col, ch)) 读作「从第 0 列开始， 把每个字符依次交给 advance 推进列」。
  • 关于 &ch 这个模式：iter() 产出的是 &char， 模式 &ch 把它拆成 ch: char（char 是 Copy，拆引用即复制）， 等价于 |col, ch| advance(col, *ch)。等价的手写循环： let mut col = 0; for &ch in &self.chars { col = advance(col, ch); }。
  • render_window 一次做完三件事：tab 展开、按列截断、 宽字符跨界用空格占位（半个字不画，免得字形被切一半）。它接收的是显示列窗口。
  • Editor::cursor() 现在返回 (显示列, 行)——不是字符下标。 这是个语义变化，所以名字和文档都要说清。移动 / 编辑仍用字符 cx。
  • Editor::new(&[String]) 收切片而不是 Vec<String>： 它只读不消费，收窄参数类型（Apollo §1.1）。这也是 clippy::needless_pass_by_value 逼出来的正确签名。
  • unicode-width 是近似：不同终端对少数字符的宽度仍有分歧。 更远一步（emoji 的 grapheme cluster、ZWJ 序列）要 unicode-segmentation，现在不做。

tab 为什么不是「+8」 tab 的语义是「跳到下一个制表位」，前进多少取决于当前列。 制表位固定在 0、8、16…：col=0 时前进 8，col=3 时前进 5，col=8 时前进 8，col=10 时前进 6。 公式 TAB_STOP - col % TAB_STOP 就是「离下一个制表位还差多少列」。

为什么必须这样——为了对齐：

a\tX          a . . . . . . X        # X 在第 8 列
abcdefg\tY    a b c d e f g Y        # Y 在第 8 列   对齐

（若只 +8：X 在第 9 列、Y 在第 15 列，错位）

这也是真实终端敲 Tab 的行为，所以 advance 算出的列宽和终端显示一致。

为什么 Row 先于编辑 编辑（插入 / 删除）要作用在「行」上，渲染要展开 tab， 高亮也要按行来。Row 是它们共同的前置。所以这次是「顺手把地基打对」，不是绕路。

小测

1. 光标位置和横向滚动该用下面哪个量？

  • 显示列 rx
  • 字符下标 cx
  • 行号 cy
  • 字节偏移
看答案

第一个。屏幕是按列画的，所以光标落在第几列、视口从第几列开始，都要用 rx。 而「移动 / 插入 / 删除」这种「第几个字符」的操作仍用 cx。

2. 一个 tab 占几列？

  • 取决于它当前在第几列
  • 永远是 1 列
  • 永远是 8 列
  • 永远是 2 列
看答案

第一个。tab 对齐到下一个制表位，所以宽度 = TAB_STOP - col % TAB_STOP： 行首的 tab 是 8 列，第 3 列处的 tab 是 5 列。正因为它依赖当前列，宽度必须边累加边算。

3. 为什么修这个 bug 要引入 Row，而不是只改光标那两行？

  • 光标、截断、滚动都依赖同一套换算
  • 因为 Vec<String> 无法保存中文
  • 因为 unicode-width 只能作用于自定义类型
  • 因为 Rust 不允许在 Editor 里算宽度
看答案

第一个。把「字符 ↔ 列」的换算集中到 Row，光标、横向滚动、截断就都走同一份逻辑， 只改一处、全部受益——这正是「深模块」省力的地方。
