一、raw mode 是什么

行为cooked moderaw mode
输入按行交给程序每次按键立即交给程序
回显终端自动显示程序自己决定显示什么
Ctrl-C / Ctrl-Z（信号）
Ctrl-S / Ctrl-Q（流控）		被终端截走，不交给程序作为普通按键交给程序
输出 \n换行并回到行首只换行，需要写 \r\n

二、用 RAII 守卫开关 raw mode

不要手写 enable_raw_mode() / disable_raw_mode() 配对——用一个 Drop 守卫，让编译器保证成对：

use std::io;

use crossterm::terminal;

/// Enters raw mode; restores it when dropped (normal return / `?` / panic).
struct RawModeGuard;

impl RawModeGuard {
    fn enter() -> io::Result<Self> {
        terminal::enable_raw_mode()?;
        Ok(Self)
    }
}

impl Drop for RawModeGuard {
    fn drop(&mut self) {
        // `Drop` must not panic: ignore the error to avoid a double-panic abort
        let _ = terminal::disable_raw_mode();
    }
}

// Usage: the binding needs a name (`_` drops immediately)
let _guard = RawModeGuard::enter()?;

记住 任何时候都不写裸的 enable_raw_mode()。 应急手段：终端没有恢复时，盲打 reset 或 stty sane 再回车。

三、事件循环骨架（现代写法）

use crossterm::event::{self, Event, KeyCode, KeyModifiers};

loop {
    let Event::Key(key) = event::read()? else {
        continue; // e.g. Resize: skip non-keyboard events
    };

    if !key.is_press() {
        continue; // Windows sends release events; macOS/Linux press-only by default
    }

    match key.code {
        KeyCode::Char('q') if key.modifiers.contains(KeyModifiers::CONTROL) => break,
        _ => { /* handle other keys */ }
    }
}

event::read() 阻塞直到有事件发生；非阻塞轮询用 event::poll(Duration)。二者不能在多线程里混用，也不能和 EventStream 混用。

四、按键的两种信息

字段类型含义 / 常用值
key.codeKeyCode Char('a')、Enter、Backspace、Delete、 Left/Right/Up/Down、Home、End、PageUp/PageDown、Tab、Esc
key.modifiersKeyModifiers bitflags：CONTROL、SHIFT、ALT……用 .contains(…) 判断
key.kindKeyEventKind Press / Release / Repeat；用 key.is_press() 便捷判断

注意单个 Esc 键是 KeyCode::Esc；方向键会被 crossterm 解析成对应的 KeyCode，你不用像 C 版那样自己读 \x1b[A 字节序列。

五、样式与清行

状态栏、命中高亮这类「重点」用属性（attribute）表示，而不是自己拼 ANSI 字节。 crossterm::style 提供可组合的 SetAttribute；设了属性，写完一定要 Reset， 否则会「漏」到后面的输出：

use crossterm::{queue, style::{Attribute, Print, SetAttribute}};

// Reverse a run of text, then restore the default style
queue!(
    stdout,
    SetAttribute(Attribute::Reverse),
    Print("status bar"),
    SetAttribute(Attribute::Reset),
)?;

清行要连「背景」一起清：先设属性，再清行，整行才会被同一底色铺满—— 这就是状态栏看起来像「一条栏」的原因。

use crossterm::terminal::{Clear, ClearType};

queue!(
    stdout,
    MoveTo(0, row),
    SetAttribute(Attribute::Reverse),
    Clear(ClearType::CurrentLine), // fill the row with the current (reverse) background
    Print(left),
)?;

刷新顺序也有讲究：本课程每帧先 Clear(ClearType::All) 再逐行画，最后用 MoveTo 把光标放回编辑器位置并 cursor::Show。刷新期间光标先 cursor::Hide，避免中途闪烁。

六、常见坑

  • 换行变楼梯：raw mode 下写 \n 只换行不回车，必须写 \r\n。
  • 输出不出现：print! 之后要 io::stdout().flush()?。
  • 守卫被提前析构：let _ = RawModeGuard::enter()?; 会立刻恢复 raw mode； 必须 let _guard = …。
  • KeyRelease 重复触发：跨平台用 key.is_press() 过滤。
  • panic 报告排版乱：报告在 Drop 之前打印，此时还在 raw mode。 解法是 panic hook（第 2 课）。
