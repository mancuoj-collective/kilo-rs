一、控制字符不再原样输出（真问题）

文件里若有不可打印字节（例如 \x1b），旧代码会把它直接写到终端—— ESC 会被终端当成转义序列，可能搞乱屏幕。原版把不可打印字节显示成反显的符号 （\x01 → A，其余 → ?），且占一列。

src/row.rs：给渲染片段加一个 control 标记，并在渲染时换成符号。

/// Display width of `ch` starting at column `col` (tabs depend on `col`).
fn advance(col: usize, ch: char) -> usize {
    if ch == '\t' {
        col + (TAB_STOP - col % TAB_STOP)
    } else {
        col + display_width(ch)
    }
}

/// Columns a char occupies; a non-printable char is shown as a one-column symbol.
fn display_width(ch: char) -> usize {
    if ch.is_control() {
        1
    } else {
        ch.width().unwrap_or(0)
    }
}

/// The symbol shown for a non-printable char (`\x01` → `A`, others → `?`), like kilo.
fn control_symbol(ch: char) -> char {
    match u32::from(ch) {
        code @ 0..=26 => char::from(b'@' + u8::try_from(code).expect("code fits in a byte")),
        _ => '?',
    }
}

二、保存失败不再退出程序

原版写盘失败时只显示 Can't save! … 然后继续编辑；旧代码把 I/O 错误 抛到 run，整个程序就退出了。改成在消息栏报告：

    match editor.save() {
        Ok(bytes) => editor.set_message(format!("{bytes} bytes written to disk")),
        // Don't quit on a write error; report it and keep editing (kilo does the same).
        Err(error) => editor.set_message(format!("Can't save! {error}")),
    }
    Ok(())

三、补齐三个按键

原版还认 PageUp/PageDown（翻页）与 Tab（插入制表符）。 src/editor.rs 加两个方法：

    /// Moves the cursor up one screen (kilo's `PAGE_UP`), clamping at the top.
    pub fn page_up(&mut self, rows: usize) {
        self.cy = self.rowoff;
        for _ in 0..rows {
            self.move_cursor(Move::Up);
        }
    }

    /// Moves the cursor down one screen (kilo's `PAGE_DOWN`), clamping at the last row.
    pub fn page_down(&mut self, rows: usize) {
        self.cy = self
            .rowoff
            .saturating_add(rows)
            .saturating_sub(1)
            .min(self.document.len());
        for _ in 0..rows {
            self.move_cursor(Move::Down);
        }
    }

src/lib.rs 的按键处理里加三条分支（翻页需要知道一屏有几行， 所以把 render 里的高度计算抽成 text_height）：

// in `handle_key`:
KeyCode::Tab => editor.insert_char('\t'),
// …
KeyCode::PageUp => {
    let (_, rows) = terminal::size()?;
    editor.page_up(text_height(rows));
}
KeyCode::PageDown => {
    let (_, rows) = terminal::size()?;
    editor.page_down(text_height(rows));
}
/// Number of text rows: terminal height minus the status and message bars, at least one
/// (with fewer than 3 rows `scroll` could otherwise push the viewport past the cursor).
fn text_height(rows: u16) -> usize {
    (rows as usize).saturating_sub(2).max(1)
}

/// Scrolls the viewport to the current terminal size, then draws one frame.
fn render(editor: &mut Editor) -> io::Result<()> {
    let (cols, rows) = terminal::size()?;
    editor.scroll(text_height(rows), (cols as usize).max(1));
    ui::draw(editor, cols, rows)
}

四、收尾优化

Rust 嵌套块注释

原版（C）一遇到 */ 就结束注释；但 Rust 允许嵌套 /* /* */ */。 把「是否在注释中」从布尔换成深度即可：进入 /* 深度 +1，遇到 */ 深度 −1， 深度 > 0 就继续。给规则加一个 nested_comments（C：false，Rust：true）， Syntax::highlight 返回 u32 深度，Row 存 comment_depth。

// inside `Syntax::highlight`, the block-comment branch:
if depth > 0 {
    if let Some(end) = self.multiline_comment_end {
        if starts_with(chars, i, end) {
            hl[i..i + end.chars().count()].fill(Highlight::MultilineComment);
            i += end.chars().count();
            depth -= 1;
            prev_sep = true;
            continue;
        }
    }
    if self.nested_comments {
        if let Some(start) = self.multiline_comment_start {
            if starts_with(chars, i, start) {
                hl[i..i + start.chars().count()].fill(Highlight::MultilineComment);
                i += start.chars().count();
                depth += 1;
                continue;
            }
        }
    }
    hl[i] = Highlight::MultilineComment;
    i += 1;
    continue;
}

按显示列截断

truncate 原来取 width 个字符；中文一个字占两列，中文文件名会溢出。 改成累加显示宽度（unicode-width），状态栏右段的长度也用显示宽度：

fn truncate(text: &str, width: u16) -> String {
    let max = usize::from(width);
    let mut used = 0;
    let mut out = String::new();
    for ch in text.chars() {
        let w = ch.width().unwrap_or(0);
        if used + w > max {
            break;
        }
        used += w;
        out.push(ch);
    }
    out
}

欢迎语居中

照原版把欢迎语居中（先输出 ~，再补到中间）：

fn welcome_line(cols: u16) -> String {
    let text = format!("{NAME} editor -- version {VERSION}");
    let max = usize::from(cols);
    let len = text_width(&text).min(max);
    let padding = max.saturating_sub(len) / 2;

    let mut line = String::new();
    if padding > 0 {
        line.push('~');
        line.push_str(&" ".repeat(padding - 1));
    }
    line.push_str(&truncate(&text, u16::try_from(len).expect("clamped to cols")));
    line
}
